# Paludism Disease Predictor 🦠

A React application that estimates clinical disease timelines and critical thresholds for *Plasmodium falciparum* malaria infections based on parasite schizogony cycles and red blood cell depletion models.

## Features

* **Biological Simulation Model:** Implements a 48-hour erythrocytic schizogony cycle calculation based on foundational parasitology principles.
* **Interactive Timeline Form:** Allows users to input symptom onset dates and immediately compute projected critical thresholds.
* **Quick Actions:** Built-in test date loaders and clear utilities for rapid evaluation.
* **Comprehensive Test Suite:** Fully tested with `@testing-library/react` and Jest to verify calculation integrity and UI behavior.

## Tech Stack

* **Frontend:** React, TypeScript, HTML5, CSS3
* **Testing:** Jest, React Testing Library, `@testing-library/jest-dom`

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

### Installation

1. Clone the repository:

   ```bash
   git clone [https://github.com/RFihobiana/paludism-disease-predictor.git](https://github.com/RFihobiana/paludism-disease-predictor.git)
   ```

2. Navigate to the project directory:

   ```bash
   cd paludism-disease-predictor
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

### Running the Application

To start the application in development mode, run:

```bash
npm start
```
